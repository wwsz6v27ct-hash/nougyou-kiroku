# 農業班記録ノート（iPhone用試作版）

## できること
- 利用者名の登録・編集・削除（記録が残っている利用者は削除不可）
- 日付・時刻の自動取得
- iPhone標準キーボードの音声入力による記録
- 記録の閲覧・編集・削除
- 利用者別・月別の月次整理用文章の生成
- JSONバックアップ・復元、CSV出力
- オフライン利用（初回読み込み後、PWAとしてキャッシュされた範囲）

## iPhoneで使う手順
このZIPを解凍しただけでは、Safariからホーム画面に追加できません。PWAとして利用するにはHTTPS対応のWebサーバーに配置する必要があります。

1. ZIPを解凍し、`index.html`、`manifest.webmanifest`、`sw.js`、アイコン2点を同じフォルダに置く。
2. これらのファイルを、職場の情報管理ルールに適合するHTTPS対応の静的Webホスティングへ配置する。
3. iPhoneのSafariで配置先URLを開く。
4. 共有ボタン →「ホーム画面に追加」。
5. ホーム画面の「農業班記録」を開く。
6. 最初に「利用者管理」から利用者名を登録する。

※公開先はURLを知る人がアクセスできる可能性があります。アプリ内データは端末内保存ですが、アプリのファイル自体を公開する場合は、個人情報を含む利用者名を初期状態で書き込まないでください。公開範囲・アクセス制限について職場の承認を得てください。

## 音声入力
記録欄をタップしてiPhoneキーボードを表示し、キーボードのマイクボタンを押して話してください。アプリ独自の音声認識ではなく、iOSの音声入力を利用します。音声入力の利用にはiOS側の設定・通信環境等が関係する場合があります。

## データ保護
- 記録データはSafari内のIndexedDBに保存します。
- Safariの履歴・Webサイトデータ削除、端末故障等でデータが失われる可能性があります。
- 定期的に「利用者管理」→「JSONバックアップ」を実行し、ファイルを安全な場所に保管してください。
- iCloudや共有ストレージに保存する場合も、職場の規程に従ってください。
- この試作版にはログイン・暗号化・クラウド同期機能はありません。端末のパスコードとFace IDを有効にしてください。

## 月次整理
「月次出力」で利用者と年月を選び「整理用文章を作成」を押します。生成された指示文と原文をChatGPTに貼り付けて整理してください。外部AIへ個人情報・健康情報等を送る前に、職場の承認と匿名化を確認してください。

## 注意
これは実務検証用の試作版です。正式運用前に、実際の端末で保存・復元・月次出力をテストし、職場の個人情報保護・記録管理ルールに適合するか確認してください。
